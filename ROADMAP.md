# Roadmap

This roadmap describes direction, not commitments or dates. Priorities can
change based on feedback and available time — this project is maintained
by a small team.

## Now

- Improve self-hosted setup documentation and first-run experience.
- Expand verification examples and test fixtures.
- Keep README and in-app behavior in sync as features change.

## Next

- Improve documentation for the image-attribution workflow end to end.
- Add more exportable examples for verification records.
- Clarify AdvProtect's scope and limitations in the docs.

## Exploring

- Additional image-format and metadata inspection options.
- Community-contributed examples and translations.
- Lighter-weight deployment options beyond Docker Compose.

## Out of scope for this repository

- Automated web-wide monitoring, takedown filing, or legal complaint
  preparation. That functionality, if it ships, will live in a separate
  product and will be announced separately — it is not part of
  JWProtect Self-Hosted.

## How to influence this roadmap

Open an issue with your use case. Real usage reports and specific
problems are the most useful input — more useful than feature requests
without context.
