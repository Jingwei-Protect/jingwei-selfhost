# HoloCard kit (Jingwei)

Iridescent same-direction fingerprint moiré, masked to the reflection band only. Study V technique; do not copy `simeydotme/pokemon-cards-css` (GPL-3.0). Do not import ProvenPix.

Homepage uses this component. Live try packs are a **browser recording** of this CSS (`capture.html` + `scripts/capture_holo_css.py`), not a numpy stand-in.

```tsx
import { HoloCard } from '../holo-card/HoloCard'

<HoloCard className="holo-card-hero">
  <img src={url} alt="" />
</HoloCard>
```
